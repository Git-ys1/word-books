## 二、屏幕上的三块内容（这是产品的核心，绝不允许搞错）

### 第一阶段：判断「认识 / 不认识」

```
┌─────────────────────────────────────────┐
│  ←        12/3051            [进度条]    │
├─────────────────────────────────────────┤
│                          ┌─────────────┐│
│                          │ act = 做；驱使││  ← ① 右上角：词根 + 中文释义
│                          └─────────────┘│
│                                          │
│                  act                     │  ← ② 中间：大单词
│                                          │
│           先自己回忆一下，再决定认不认识      │  ← ③ 提示语
│                                          │
│         ┌──────────────────────┐         │
│         │        + 拆解         │         │  ← ④ 拆解按钮（折叠状态）
│         └──────────────────────┘         │
│                                          │
│      ┌──────────┐  ┌──────────┐         │
│      │  不认识   │  │   认识    │         │  ← ⑤ 判定按钮
│      └──────────┘  └──────────┘         │
└─────────────────────────────────────────┘
```

**① 右上角：词根 + 词根中文释义** —— ⚠️ 这是最容易做错的地方

| 词书 | 右上角显示什么 | 例子 |
| --- | --- | --- |
| 书1 | `△` 那一行的原文，**去掉 △**，即「词根 = 释义」 | `act = 做；驱使` |
| 书2 | PDF **第一列**原样内容（词根 + 中文意思） | `tend/tent/tens 伸展，趋向` |

**规则**：
- 有词根 → 显示 `词根 = 释义`
- 没有词根（书1 的散词区、书2 第8-10天）→ 显示该词所在组的标题（如「散词区」「第八天」），不留空白
- **绝对不能只显示英文词根而丢掉中文释义**

**② 中间：大单词** —— 只放单词本身，字号最大
- 不加音标
- 不加释义（用户要先自己回忆）

**③ 提示语**：`先自己回忆一下，再决定认不认识`

**④ 拆解按钮**：默认折叠。点击后展开「记忆内容」

**⑤ 判定按钮**：`不认识` / `认识`

### 点击「拆解」后展开什么

这是记忆的核心，必须把「这个词怎么构成的、怎么记住的」完整展示出来。

```
┌─────────────────────────────────────────┐
│                          ┌─────────────┐│
│                          │ act = 做；驱使││
│                          └─────────────┘│
│                  act                     │
│                                          │
│  ┌────────────────────────────────────┐ │
│  │  act(词根) = act(词根) = 做(释义)   │ │  ← 彩色拆解，按语义角色着色
│  │                                     │ │
│  │  记忆：…                            │ │  ← 书1 如果有讲记忆方法
│  └────────────────────────────────────┘ │
│         ┌──────────────────┐            │
│         │      收起         │            │
│         └──────────────────┘            │
│      ┌──────────┐  ┌──────────┐        │
│      │  不认识   │  │   认识    │        │
│      └──────────┘  └──────────┘        │
└─────────────────────────────────────────┘
```

**拆解内容规则**：

| 词书 | 拆解显示什么 |
| --- | --- |
| 书1 | 词条行第 2、3 段：拆解式 + 中文对照，如 `act=act=做` |
| 书2 | PDF 最后一列「词根记忆 / 联想记忆」原文 |

**⚠️ 绝不允许的情况**：点开拆解后，看到的还是单词本身（如 `act` → 拆解 → `act`），**没有任何信息增量**。这就是「有些词还在拆解后就是他自己，啥也没有」的问题。

**正确处理**：如果该词原文确实没有拆解信息，拆解区应该显示**有信息量的内容**：
- 该词的完整释义（`v.行动；n.法令`）
- 或该词所在词根的说明

**颜色规则**（按语义角色）：

| role | 含义 | 颜色 |
| --- | --- | --- |
| `root` | 词根本体（英文） | 蓝紫 |
| `affix` | 词缀（前缀/后缀） | 琥珀 |
| `latin` | 其它英文词素 | 青绿 |
| `meaning` | 中文释义 | **墨黑**（中文永远不是词缀） |
| `pos` | 词性缩写（n. v. a.） | 淡灰 |
| `link` | 连接符 `=` `+` | 极淡，不占色块 |

### 第二阶段：中文释义四选一

只有「完全随机」模式直接进这一阶段；其他模式在一组学完后进入。

```
┌─────────────────────────────────────────┐
│                          ┌─────────────┐│
│                          │ act = 做；驱使││
│                          └─────────────┘│
│                  act                     │
│                                          │
│            选出正确的中文释义              │
│                                          │
│  ┌────────────────────────────────────┐ │
│  │ A  n.行动；n.法令                   │ │
│  ├────────────────────────────────────┤ │
│  │ B  a.积极的；活跃的                 │ │
│  ├────────────────────────────────────┤ │
│  │ C  a.惰性的                         │ │
│  ├────────────────────────────────────┤ │
│  │ D  n.活动                           │ │
│  └────────────────────────────────────┘ │
└─────────────────────────────────────────┘
```

- 4 个选项，干扰项从同一词书随机抽取
- 排除释义完全相同的候选（杜绝两个正确答案）
- 选对 → 进度 +1
- 选错 → 进度不变，该词延后

## 三、三种背诵模式

| 模式 | 组顺序 | 组内顺序 | 是否选起始组 | 第一阶段 | 第二阶段 |
| --- | --- | --- | --- | --- | --- |
| **完全顺序** | 固定 | 固定 | **是** | 认识/不认识 | 组内学完后四选一 |
| **组内随机** | 固定 | 随机 | **是** | 认识/不认识 | 组内学完后四选一 |
| **完全随机** | 全书打乱 | 全书打乱 | 否 | — | **直接四选一** |

**选起始组的规则**（完全顺序 + 组内随机都有）：
- 列出所有组，可从任意组开始
- 选定组之前的组**接到末尾**继续背，**不漏任何词**
- 例：选第 30 组 → 顺序变成 30,31,...,467,1,2,...,29

## 四、「不认识」的处理（间隔重复）

### 完全顺序 / 组内随机

```
判定「不认识」
  → 该词出队
  → 插到剩余队列的第 N 个之后（默认 N=8）
  → 进度不变
  → 提示「稍后再见 · 已排到第 9 个之后」
```

**为什么是 8**：
- 记忆科学：回忆失败后最优间隔在后续 5~10 项
- 手机上一个词 3~6 秒，8 个 ≈ 25~45 秒，记忆还热但需要主动回想
- 队列只膨胀约 12.5%，进度条稳定

**边界**：N 夹在 2~20。N=1 等于插回队首（立刻重问），没有复习价值。剩余词不足 N 时落队尾，永不丢词。

### 完全随机

```
认识 → 进复习池（reviewPool）
不认识 → 进错词池（wrongPool）
```

**退出时**：如果错词池不为空 → 弹窗强制转入「错词复习」，也可显式选择「略过，直接退出」
**再次进入**：队列跑完但错词池有词 → 自动进入错词复习

## 七、数据格式（JSON）

```jsonc
{
  "book": "book1",
  "rootGroups": [
    {
      "root": "act",                    // 词根本体（英文）
      "meaning": "做；驱使",             // 词根中文释义
      "entries": [
        {
          "word": "act",                // 单词
          "meaning": "v.行动；n.法令",   // 单词释义
          "segments": [                 // 拆解片段（按顺序）
            { "text": "act", "role": "root" },
            { "text": "=",   "role": "link" },
            { "text": "act", "role": "root" },
            { "text": "=",   "role": "link" },
            { "text": "做",  "role": "meaning" }
          ],
          "memory": ""                  // 记忆方法（书2用得多）
        }
      ]
    }
  ]
}
```

**书2 结构**：`groups: [{ day, title, entries }]`，entry 字段同上，额外有 `rootMeaning`。

## 八、质量标准（硬要求）

1. **每个词的释义必须与原文一致** —— 释义错位比提取不全更严重
2. **右上角必须显示词根 + 中文释义** —— 只有英文算不合格
3. **拆解必须有信息增量** —— 点开还只有单词本身算不合格
4. **中文必须是墨黑色** —— 标成词缀色算不合格
5. **不漏词** —— 原文有的词必须有，除非明确是页签/页眉
6. **不臆造** —— 原文没有的不编（如 `catastrophe` 原文无释义，就留空并标注）
